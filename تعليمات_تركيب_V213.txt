تحديث لوحة يامو V213 الكامل

الملف يحتوي جميع تعديلات الرسائل السابقة مع التصميم الجديد، وليس تعديلًا منفصلًا ناقصًا.

1) انسخ مجلدي src وsupabase إلى مجلد مشروع yamo-admin-panel الموجود فيه package.json.
2) وافق على Replace.
3) افتح Supabase SQL Editor.
4) شغّل محتوى الملف كاملًا:
   supabase/migrations/202608290001_yamo_message_management.sql
5) في GitHub Desktop اكتب:
   Add V213 premium message pricing UI
6) اضغط Commit ثم Push origin.
7) بعد اكتمال النشر افتح اللوحة واضغط Ctrl + F5.

النتيجة:
- الأسعار باللغة الإنجليزية.
- كل الأرقام والتواريخ بأرقام إنجليزية.
- أزرار زيادة ونقصان مخصصة بدل الأسهم القديمة.
- تصميم مضيء واحترافي مع الحفاظ على ألوان يامو.
