تحديث لوحة يامو V212 — إدارة الرسائل والمكالمات

أولًا: انسخ الملفات إلى مشروع yamo-admin-panel ووافق على Replace.

ثانيًا: افتح Supabase ثم SQL Editor، وشغّل محتوى الملف كاملًا:
supabase/migrations/202608290001_yamo_message_management.sql

ثالثًا: ارجع إلى GitHub Desktop وتأكد أن الملفات الجديدة والمعدلة ظاهرة، ثم:
1) Summary: Add V212 message management dashboard
2) Commit to main
3) Push origin

بعد انتهاء النشر افتح لوحة التحكم واضغط Ctrl + F5.

مهم:
- الصلاحيات الجديدة تظهر داخل قسم «مسؤولو اللوحة» تلقائيًا.
- قسم الرسائل يحتوي: نظرة عامة، الأسعار والأرباح، المستخدمون النشطون، اقتراح الحسابات، وأرشيف المحادثات.
- يجب أن يكون SQL الخاص بـ V211 منفذًا قبل SQL الخاص بـ V212.
