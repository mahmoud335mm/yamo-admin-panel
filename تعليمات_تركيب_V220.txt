تركيب Yamo Admin V220

1) ارفع مجلد اللوحة كاملًا إلى GitHub Desktop.
2) شغّل RUN_THIS_SQL_V220_INSTANT_MESSAGES_STUDIO.sql في Supabase بعد نجاح ملف V219.
3) تأكد من ظهور pg_notify بدون خطأ.
4) حدّث الموقع تحديثًا إجباريًا Ctrl + F5.

النتيجة:
- البنرات: قسم مستقل.
- الرسائل الفورية: قسم مستقل بتصميم ومعاينة وإحصائيات كاملة.
- رسائل النظام التلقائية: قسم مستقل بقوالبه وسجل إرساله.
- سجل الرسائل الفورية لا يعرض رسائل الدخلات أو رسائل النظام.
