Yamo Admin V211 — أرشيف الرسائل والوسائط

- بحث مباشر بالـ ID.
- عرض جميع الأشخاص الذين تحدث معهم المستخدم.
- صور المستخدمين داخل القائمة ورأس المحادثة.
- عرض الصور الأصلية داخل الشات مع معاينة كبيرة.
- تمييز الرسائل المحذوفة مع وقت الحذف وهوية الحاذف.
- الاحتفاظ بالرسالة والوسائط بعد حذف المستخدم.
- منع الحذف الفعلي لملفات chat-media بالكامل ما دام Trigger الحماية مفعّلًا.
- كل بحث وفتح محادثة مسجل في سجل الإدارة.
- صلاحية messages.read مستقلة وممنوحة افتراضيًا إلى super_admin وadmin وauditor.
- القسم عرض فقط ولا يرسل أو يعدل رسائل المستخدمين.

التشغيل:
1) طبّق supabase/migrations/202608280001_yamo_admin_message_archive.sql.
2) نفّذ npm install ثم npm run build.
3) انشر لوحة التحكم.
