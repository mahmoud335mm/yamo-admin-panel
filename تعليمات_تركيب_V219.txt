تركيب تحديث رسائل النظام V219

1) ارفع مجلد اللوحة كاملًا إلى مستودع yamo-admin-panel باستخدام GitHub Desktop.
2) شغّل RUN_THIS_SQL_V219_SYSTEM_MESSAGES.sql كاملًا في Supabase SQL Editor بعد V218.
3) تأكد أن آخر نتيجة هي pg_notify بدون خطأ ثم حدّث اللوحة تحديثًا إجباريًا.
4) ستجد ثلاثة أقسام مستقلة: البنرات، الرسائل الفورية، رسائل النظام التلقائية.

قسم رسائل النظام:
- القوالب والأنظمة: تشغيل وإيقاف كل حدث منفردًا.
- تعديل ومعاينة: النص العربي والإنجليزي والصورة والرابط والقنوات ومنع التكرار.
- إرسال تجربة: أدخل ID مستخدم حقيقي وقيم المتغيرات ثم أرسل له وحده.
- سجل الإرسال: المستلم والحالة والمحاولات والخطأ وإعادة المحاولة.

الربط التلقائي المباشر مفعّل للجداول الموجودة: الحسابات، دعوات ومضيفو الوكالات، VIP، السحب، العلاقات، الفعاليات والتارجت عند وجود host_targets.
لبقية وظائف التطبيق أو أي نظام جديد، يستدعي السيرفر الدالة emit_yamo_system_event عند نجاح العملية. هذا يمنع إرسال رسائل مزيفة أو مكررة لأن الحدث يأتي بعد نجاح معاملة السيرفر.
